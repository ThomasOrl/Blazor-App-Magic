# Blazor-App-Magic

// Projet C# avec Blazer comme FrameWork.

Description:
Le jeu comportera une map avec différents emplacements de coffres, de trésors ou d’objets à récupérer.
Il comportera 3 classes d'héros différentes (Mages, Soldats et voleurs).
Des Monstres seront placés aux alentours des coffres pour les garder, le but sera de les éviter afin de récupérer les coffres ou autres trésors disponibles.

Objectif du jeu:
 - Choisir un héros au début du jeu, chaque héros ayant une compétence particulière, le choix sera donc déterminant pour la suite du jeu.
 - Pouvoir se déplacer sur la map et se rendre aux différents points afin de pouvoir récupérer les récompenses.
 - Les ramener une fois collectés à la maison principale du héros.

Fonctionnalités:
 - Avoir un sac (Porte-monnaie du héros)
 - Une réserve de trésors dans la maison principale du héros.
 - Pouvoir se déplacer librement avec les flèches de direction.
 - Pouvoir récupérer les différents trésors.
 - Prévoir un mouvement régulier des monstres aux alentours des objets à récupérer.
